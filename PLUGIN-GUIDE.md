# Extending the companion

src/catalog.cjs declares names, categories, local icons, allowed actions and action validation. src/workspace.cjs persists four assignments and dispatches service launchers, app launchers, OBS calls, media commands and configured shortcuts. Add a catalog entry and a validated dispatcher branch for a new native integration. Launcher entries must not claim account control. src/plugins retains the original Spotify transport registry.

src/desk.js automatically renders the catalog and assignment editor. Additional connection forms belong in the Connections page. Native code is restricted to the main process; the isolated renderer calls narrow validated IPC handlers. Plugins are trusted application code, not an untrusted third-party marketplace. No downloaded code is loaded automatically.

src/strip.cjs owns 1920x550 transparent rendering: four 80x78 tiles in the narrow strip, with the shortcut at the bottom. Brand SVGs are local assets generated by scripts/build-icons.cjs from Simple Icons; generic tools use original artwork. Respect brand identity when adding assets.

Display slots 2/3 hold idle Caps states; 4/5 hold L1 states; 6–9 preload all four navigation highlights. Slot 10 permits idle widget updates. Navigation never uploads an image. Repeated selection must not resend the toggle command. Caps Lock exits plugin mode and selects its idle state immediately. Do not replace this with uploads on each Caps press. Upload readback uses the half-size 960x275 preview, with color samples and dimensions checked. SkinEngine/native plugin APIs are not implemented.

src/system.ps1 observes only Caps Lock state and emits changes through a local pipe; no typed text is retained. src/system.cjs owns the helper lifecycle. Shortcut sending accepts validated key codes, never arbitrary PowerShell. OBS accepts localhost only and keeps its password in memory. App launching uses an explicit local picker and saved assignment.

src/keymap.cjs reads the actual 68-key map, checks serial/snapshot/unsaved changes, backs up before writing and compares the whole readback. Multi-key pre-save failures discard staged changes. Uncertain saves invalidate the snapshot. Do not bypass these checks or expose arbitrary HID requests to the renderer.

Run npm test, npm run check and electron . --verify. Physical hardware tests must report their real outcomes separately from software assertions. Keep hardware-backup, diagnostics and user settings out of shared source packages.
