# Share Centerpiece Companion

Share this public download page:

https://github.com/lilwoii/centerpiece-companion/releases

Tell people to open the newest release and download the `.exe` installer under **Assets**. They do not need a GitHub account, developer tools, source code ZIP, `.blockmap`, or `.yml` files.

Describe it as a **free, unofficial Windows community preview for the 68-key Centerpiece Pro**, not an official Finalmouse product or finished replacement for every advertised integration. It has been tested on one keyboard. The installer is currently unsigned.

New users choose installation/update folders, connect their keyboard, close XPANEL after saving its edits, and click **Set up my keyboard**. Then they assign plugins, configure their own connections and apply widgets. L1+P selects plugin actions; L1+/ cycles widgets. The companion can stay hidden in the tray.

Link to the README for setup and current limitations:

https://github.com/lilwoii/centerpiece-companion#readme

For future releases, people use the companion's update button or revisit the release page. Feature requests can be submitted from the app using Discord sign-in.

Publish only the public release link or the sanitized installer from that release. Never upload your personal installed folder, AppData, credentials, diagnostics, or hardware backups. Sharing this repository does not grant access to your other private repositories.
