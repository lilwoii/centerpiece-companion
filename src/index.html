In OBS, open Tools → WebSocket Server Settings and enable the server. Use its port and password below. This app connects only to OBS on this PC.

Password stays in memory for this session. No streaming starts automatically.

Local weather

Not configured

Use Windows location or choose a city. Your coordinates go directly to Open-Meteo for weather; no shared account or location is bundled.

Weather data by Open-Meteo · CC BY 4.0. Windows location may need Location services enabled in Windows Settings.

System sensors & microphone

NVIDIA temperature is read through its installed driver tool when available. CPU/AMD temperatures need an existing Libre Hardware Monitor web server. This app does not install a hardware driver or require administrator access. If unavailable, CPU shows load and temperature widgets show “No sensor”.

Twitch chat

Not connected

Connect in your browser to display chat. Your connection is encrypted and saved on this PC. No access tokens to copy, and no chat messages are sent.

Restore companion setup

Restores the original L1+P and L1+/ actions and previous overlay selection. Your other key remaps remain. Cached companion images stay in the reserved slots.

Other apps

Spotify connects through Windows. For Discord mute, voice effects, soundboards and other app controls, select “Send configured shortcut” and match the shortcut you set in that app. Website actions open your existing browser session.
