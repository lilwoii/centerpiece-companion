# Stillwater shoreline

`garden-shoreline.png` is original artwork drawn specifically for the Companion test build using Canvas paths, deterministic grain, gradients, stones and water-lily shapes. It does not contain material from the owner's Koi package or a third-party skin.

The transparent 1920 × 550 image is embedded in `studio/pond-presets.js`, so exported projects remain portable. In Studio it is one editable image layer named **Stone edge & water lilies**. The five koi are separate procedural fish layers with independent color, geometry and swimming settings.

This artwork and the preset are covered by the repository's license. The preset is an editable browser preview, not a verified native Unreal package.
