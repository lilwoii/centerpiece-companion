# Interactive creator collection

Eleven original interactive Studio projects, plus the earlier Ignition launch scene. Open these `.cpskin` files in Skin Studio. They contain editable layer settings, keyboard/pointer interactions and all required photographic assets. No network image links are needed.

The five animated designs are Lantern festival, Paper ocean, Neon speedway, Clockwork garden and Prism bloom. The five photographic designs are Tidal observatory, Alpine reflection, Storm window, Ember forge and Moon tranquility. Atlas · first light is a separate, more realistic rocket scene with a photographic environment and a separately animated vehicle.

Press any key or click the preview to test most scenes. Atlas uses Space or a click for an eight-second launch sequence. Neon speedway uses Space for a boost. Storm window uses Space for a brief lightning glow. Speed zero stops ambient animation; keyboard reactions remain available while testing.

These are source projects, not cooked `.pak` files. The accompanying Unreal source includes 3D scene assemblies and input handling. Native rendering differs from the browser preview and requires compilation, texture binding, Android cooking and physical keyboard verification. A newer Unreal Editor version does not establish compatibility with the keyboard firmware.

`previews/` contains actual renders of each Studio scene at 1920 × 550. `studio/assets/collection/PROVENANCE.json` records the original image prompts. Photographic images were generated for this project; no frames or assets from the user's video reference were extracted.

The library is local in this development build. No community submission, release or updater publication is performed by these files.
