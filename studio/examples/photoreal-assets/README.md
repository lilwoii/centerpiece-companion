# Photographic reactive collection

Ten editable 1920 × 550 scenes appear at the top of Skin Studio's scene library. Each combines generated photographic artwork, ambient motion and keyboard reactions. These are layered real-time scenes, not video clips.

## Use and customize

Skin Studio → Create a custom scene → Build your scene → Test reactions → Use on my keyboard. Ready-made scenes are available separately in Skin library.

Unchanged included scenes use bundled native packages without Unreal. Matching completed builds are reused. Edited scenes require a new native build. Select a layer to change its appearance, movement and reactions; save the editable project to retain your design.

For native builds, install Epic Games Launcher from https://www.unrealengine.com/download → Unreal Engine → Library → install 4.27 → return to Companion. Missing Microsoft creator tools are prepared with Windows approval when required. Advanced Blueprint/material editing opens Unreal's own editor; the complete Unreal editor is not embedded in Companion. PNG/MP4 exports do not require Unreal.

## Artwork and validation

Backgrounds and transparent koi/jellyfish subjects were made with the built-in image-generation tool. Available generation prompts are in generation-prompts.json. Every editable .cpskin includes its artwork.

All ten scenes compile and cook for Android ASTC and have offline native ambient/input render checks. Eight koi independently pass native held-key wait, approach and release checks. Physical keyboard playback/performance testing is deferred; these checks do not certify every firmware/device combination. Hard/soft press sensing is not verified: reaction strength is editable, not advertised as measured pressure.
