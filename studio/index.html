Create a reactive skin
For your first skin, use the layer designer below; you do not need to learn Blueprint graphs. Use the advanced Unreal editor when you need deeper control. Your editable projects stay on this PC.
  1. Choose your starting point
    Open Skin library and choose Test preview, or click New for a blank canvas. Import a PNG, JPEG or WebP as a background. Use Convert image to frame a picture and save a lossless PNG at 1920 × 550 pixels. Smaller pictures keep their original detail unless you choose enlargement.
  2. Build with separate layers
    Add rain, stars, fish, text or images. Set each layer’s position, color, size and motion. A photograph is a flat background: add separate fish or other objects if you want them to move independently.
  3. Give your keys a reaction
    Select keys on the keyboard preview, open Interactions and add a reaction. Choose which layer reacts, then adjust its strength, duration and area. Try lightning over a landscape, ripples on water, or nearby fish swimming away.
  4. Test and refine
    Test with my keys runs the app preview. Large preview gives you more room; Back to editor returns to your controls. This preview does not upload a skin.
  5. Build for your keyboard
    Use on my keyboard builds and applies the current design. Creating a new .pak requires Unreal Engine 4.27 and creator tools. Companion detects installed tools. Review the destination slot before uploading; XPANEL skins and Companion project spaces are separate.
  6. Save and share
    Save to an empty Companion project space to keep editing later. Export a .cpskin for an editable backup. Share a tested .pak download link through Publish to community; approved submissions appear in the community feed.
Try the Storm meadow recipe
Landscape image → separate tornado layer with drift → rain layer → lightning layer with a key-press reaction. Each part stays editable. A compiled skin from elsewhere cannot be converted back into its original Unreal project.
Animate your own photo
Choose Animate photo next to Import image. Select a photo with a distinct subject and choose Find subject automatically. Review the transparent cutout, choose its movement and key reaction, then add it to your scene. It stays editable as an image layer. Use a separate background image for the scenery behind it.
Draw a route
Select an unlocked layer and choose Draw motion path. Drag a route across the keyboard and apply it. Studio creates X/Y keyframes that you can adjust in the timeline. The loop option brings the object back to its starting position.
Continue in Unreal
Start in the layer designer for the simplest workflow. When you need Blueprint graphs or material editing, choose Unreal editor → Edit in Unreal. Companion builds the source project if needed; applying it to the keyboard is a separate step. This creates an editable Unreal copy and opens it inside the desktop app. In Unreal, open the Content Browser and double-click a Blueprint or material to edit it. Use Save All before returning to Studio. Your Unreal copy stays selected: choose Build saved Unreal edits to build and apply that version. Reopen the same saved project to continue; creating another copy starts again from the Studio design. Unreal graph changes stay in that project and do not turn back into Studio layers. Keyboard builds require Unreal 4.27 and runtime-compatible assets.
